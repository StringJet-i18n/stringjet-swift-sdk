# StringJet iOS SDK

StringJet lets you manage localization keys and translations for your app with OTA delivery and fast integration workflows.

## Install (Swift Package Manager)

Use **File -> Add Package Dependencies...** in Xcode and add:

`https://github.com/StringJet-i18n/stringjet-swift-sdk.git`

Or in `Package.swift`:

```swift
.package(url: "https://github.com/StringJet-i18n/stringjet-swift-sdk.git", .upToNextMinor(from: "0.1.0"))
```
